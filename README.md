# Tensor

Custom implementation of a tensor library based on ATen/Pytorch with C++17.

Support: type promotion, different backends (CPU and CUDA).


Implemnetation of SIMD operations is going to be based on this:
https://github.com/yuninxia/hands-on-simd-programming
